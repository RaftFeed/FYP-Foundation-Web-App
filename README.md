# FYP Foundation Web App

Landing page prototype for the FYP Foundation tutoring platform, built with React, Vite, and Tailwind CSS v4.

## Stack

- React 18
- Vite 6
- Tailwind CSS 4
- Lucide React

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Project structure

```text
src/
  app/
    App.tsx
    components/
  styles/
```

## Notes

- The project has been cleaned up from unused shadcn/Figma scaffold files and unnecessary dependencies.
- `node_modules` and build output should not be committed to GitHub.
